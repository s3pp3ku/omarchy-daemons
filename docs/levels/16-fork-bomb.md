## Identity
- Map size: 600 × 650
- Daemons / quota / time / minimum release rate: 64 / 60 (94%) / 9:00 / 97
- Skills: Blocker 3, Builder 7, Basher 3
- Goal: Sixty-four daemons from four hatches at the top of the release rate; six floors of pits and walls. There is no time to scout, so pits are guarded as the stream pours in.
- Puzzle sentence: **Guard → Wall → Guard → Wall → Guard → Wall → Pit**

## Anti-triviality
- A random search (`KMIN=2 KMAX=4 node tools/random.js fork-bomb 6000`) found no win with two to four random assignments.

## What we learned
- Three guards give a perfect run. Leaving the last pit unguarded costs nothing; leaving the fourth costs four daemons, which is exactly what the quota allows.
- Guards work best early on a floor; by the last pit the stream is thin enough to ignore.
- Walls are free (a basher releases nothing and loses nobody).
