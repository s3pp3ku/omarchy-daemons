# Omarchy Lemmings Agent Pack

Copy these files into the root of the game repository.

- `AGENTS.md`: canonical game/level-design brief.
- `LEVEL_DESIGN_TEMPLATE.md`: mandatory worksheet for each map.
- `START_HERE_PROMPT.txt`: recommended first Codex prompt.
- `art/reference/`: the two Omarchy Lemmings concept sheets.

The central rule is: prove the level-design system with one genuinely good,
multi-solution puzzle before asking the agent to generate the full campaign.
